# Telugu Bridal Artistry Portfolio

## Overview
A beautiful static portfolio website for Supriya.S, a makeup artist specializing in bridal and party makeup.

## Project Structure
- `index.html` - Main website file (single-page application with embedded CSS and JavaScript)
- `server.py` - Simple Python HTTP server for development
- `README.md` - Basic project description

## Technology Stack
- Static HTML/CSS/JavaScript
- Python HTTP server for local development

## Running the Project
The website runs on port 5000 using a simple Python HTTP server:
```bash
python server.py
```

## Deployment
Configured as a static site deployment, serving from the root directory.

## Features
- Responsive design for mobile and desktop
- Image galleries with auto-scroll for bridal, party, and miscellaneous makeup looks
- Modal image viewer with navigation
- Contact form
- Social media links (Instagram, YouTube, Email)
- Testimonials section
